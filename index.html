DashAgent · 자연어 → SQL 자율 분석 에이전트
넥슨코리아 · 2026.03 — 진행중
LLM AgentFull-StackHITLSecurity

복잡한 SQL·스키마를 몰라도 자연어 질의만으로 데이터를 추출하고 인터랙티브 대시보드를 자동 생성하는 사내 AI 데이터 분석 웹앱. PRD부터 풀스택 구현까지 직접 빌드.

단순한 Text-to-SQL이 아니라, LLM의 비결정성을 제품 품질로 흡수하는 것을 핵심 설계 원칙으로 삼았습니다.

  • 2단계 LLM 파이프라인 — 자연어를 DashboardSpec으로 1차 파싱 후 SQL 생성, 같은 질의에 일관된 결과 보장
  • Pre/Post 정합성 검증 — GROUP BY 누락·이상치·중복을 자동 검출하고 색상 뱃지로 투명하게 노출 (Human-in-the-loop)
  • 스키마 마스킹 보안 — 실제 DB·컬럼명을 외부 LLM에 전송하지 않는 별칭 통신 구조
  • SpecKit 하네스 엔지니어링 — 5종 명세를 검증 가능한 형태로 정제, Cursor로 PRD→코드 풀사이클 운영

AI 시대의 기획자에게 필요한 건, 의도를 명확한 명세로 옮기고 AI의 불확실성을 신뢰할 수 있는 구조로 다듬는 능력이라고 생각합니다.
